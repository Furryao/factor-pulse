# 因子轮动雷达

A 股周频与月频因子研究仪表盘。

公开网站：https://furryao.github.io/factor-pulse/

行情数据截至 2026-10-09。提供股票池切换、因子排序、行业诊断和历史热力图；未结算信号仅用于观察，不进入收益和排名。研究结果不构成交易指令。

`site.zip` 为网站静态发布包，GitHub Actions 解压后部署至 GitHub Pages。

## 投资者版 · 看懂市场

公开网站：https://furryao.github.io/factor-pulse/investor/

从追涨、跌后修复、公司规模、盈利估值、价格波动和成交升温六种行为理解市场。支持按周/按月观察、3/6/12 个月历史比较和浏览器本地关注收藏。使用截至 2026-10-09 的研究快照，不是实时行情。

`investor/` 是独立投资者版的静态网站文件。发布时复制至 `/investor/`，专业版继续位于根路径。
